**Hekili Forever** is a priority helper addon for the WoW Forever client. It shows the ability to press next and the few after it, worked out by simulating the next few seconds of the fight with the priority in use. It does not press anything for the player. Hekili Forever is a fork of the original Hekili, rebuilt for a client that hides many combat values from addons.

The built-in priorities are translated from the rotations at [wowsims.com](https://wowsims.com). Players can copy and edit them, and developers can extend the class addons.

## About the estimates

The Forever client hides resources such as energy, rage and mana, and target health, from addons at all times. During combat it also hides cooldown times and aura durations. Hekili Forever estimates these values from what the game still reports, so a recommendation can appear a moment after the ability becomes usable. [What Hekili Forever can and cannot know](What-Hekili-Forever-Can-And-Cannot-Know) lists which values are read and which are estimated. The [Accuracy](Accuracy) page reports, for most specializations, how closely the recommendations follow wowsims.

## Getting the addon and help

- Download from [CurseForge](https://www.curseforge.com/wow/addons/hekili-forever) or the [releases page](https://github.com/zmsl/hekili/releases), as [Installing](Installing) describes. Update the core and the class addons together.
- For a problem, read [Troubleshooting and FAQ](Troubleshooting-And-FAQ) first. Then open an issue at [github.com/zmsl/hekili/issues](https://github.com/zmsl/hekili/issues) with a snapshot, as [Reporting a problem](Reporting-A-Problem) describes. Problems with Hekili Forever do not go to the original Hekili project.
