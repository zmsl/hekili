## Page types

- Each page is one type: tutorial, how-to, reference or explanation; Wikipedia's Manual of Style is the reference. Source: `docs/wiki/README.md`

## Writing

- Lead first, no Introduction heading; neutral tone; date changeable facts (as of vX.Y.Z); link the first mention only; no first person; sentence-case headings. Source: `docs/wiki/README.md`

## Terminology

- Hekili Forever in prose; priority on player pages, APL on Write priorities pages; UI labels bold and exact; expressions and commands in code. Source: `docs/wiki/README.md`

## Formatting

- No H1, H2 and H3 only; infobox as a two-column table after the lead; n/a stated under a table; callouts with a bold lead-in; fenced code with a language; screenshots in images/ as Page-Name-n.png. Source: `docs/wiki/README.md`
