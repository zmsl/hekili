The **displays reference** lists every option under **/hekili > Displays**: the options shared by all displays, and the tabs of each display. The tables are generated from the addon, with each option's default. How to use the options is described in [Setting up displays](Setting-Up-Displays); what the displays show is explained in [Reading the displays](Reading-The-Displays).

| Displays | |
|---|---|
| Where | **/hekili > Displays** |
| Built-in displays | **Primary**, **AOE**, **Cooldowns**, **Defensives**, **Interrupts** |
| Styles | Classic, Timeline |
| Saved | In your profile |

## Options for every display

The **Displays** page itself holds the buttons that open each display, **Multiple** (change several displays at once), **Notification Panel**, the font of all display text, **Action Bar Glow** ([Action Bar Glow](Action-Bar-Glow)) and **Share Styles** ([Profiles and sharing](Profiles-And-Sharing)).

<!-- GENERATED:options-displays-all -->
<!-- /GENERATED -->

The **Notification Panel** is a line of text on the screen where Hekili Forever reports a toggle or mode change. When it is turned off, those messages go to the chat window.

## Timeline style

The **Style** tab of a display that uses the Timeline style. Its sections are **Now** (the circle for a focus ability), **Next** (the box with the ability to press now), **Lane** (the abilities after it) and **Timeline** (the lane's time axis, ruler and focus settings).
